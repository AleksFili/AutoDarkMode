# AutoDarkMode

Фоновое переключение темы Windows и приложений для текущего пользователя. Светлая тема включается на восходе, тёмная — за 20 минут до расчётного заката.

Скрипт рассчитывает время по координатам и формулам [NOAA](https://gml.noaa.gov/grad/solcalc/calcdetails.html). Интернет для работы не нужен. Планировщик заданий запускает проверку при входе в Windows и раз в минуту, без видимого окна. При полярном дне действует светлая тема, при полярной ночи — тёмная.

## Установка

На Windows с Windows PowerShell 5.1 и включённым VBScript запустите из папки проекта:

```powershell
.\Install.ps1 -Latitude 55.7558 -Longitude 37.6173
```

В примере указана Москва. Укажите свои координаты в десятичных градусах. Повторный запуск установщика обновит их. Координаты хранятся в локальном файле `location.json`. Планировщик запускает скрипты из этой папки, поэтому после её перемещения установщик нужно запустить снова.

## Проверка и отключение

```powershell
.\Update-Theme.ps1 -Preview
.\Test.ps1
.\Uninstall.ps1
```

`-Preview` показывает расписание в часовом поясе Windows. Удаление задания прекращает автоматическое переключение.
